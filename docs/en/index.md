# MTG Deck Manager – documentation

MTG Deck Manager is a desktop app (macOS, Windows) for Magic: The Gathering players with a paper
collection or an MTG Arena account. Everything runs on your computer; card data comes from
[Scryfall](https://scryfall.com) and works offline once downloaded.
